# Fixture provenance

Every sample here is **synthetic**, generated by the `make.mjs` beside it from
the documented on-disk layout. None of it is real evidence, and none of it came
from a real machine or a real person's disk.

That is deliberate twice over:

- Real forensic artifacts carry real usernames, paths and timestamps. They do
  not belong in a public repository.
- A generated fixture is an **independent oracle**. It is written from the
  format documentation rather than from parser output, so a parser that matches
  it is agreeing with the format and not merely with itself. A sample captured
  from a parser's own output can only ever confirm that parser's bugs.

CI regenerates every fixture and fails if the committed bytes drift, so the
samples can always be audited against the generator that claims to produce them.

| Directory | Format reference |
|---|---|
| `recyclebin/` | [libyal dtformats — Windows Recycle Bin](https://github.com/libyal/dtformats/blob/main/documentation/Windows%20Recycle%20Bin.asciidoc) |

If a real-world sample is ever added, it must come from a public corpus with a
licence that permits redistribution, and the licence and source URL must be
recorded in this table.
